# GitHub

**In one line:** a quiet, centred homepage for the developer platform, with a mascot and a pixel grid doing the personality work.

## Colour
Nearly everything is white or near-white, with black text and a black Sign up pill in the nav. Green (#08872B) is reserved for the main email sign-up button, and purple (#8534F3) is the link colour. The only multi-colour moments are thin rainbow rules (blue, green, lilac, pink) that run under sections and the confetti-like pixel blocks near the footer.

## Type
Mona Sans in a regular weight at about 56px for the headline, tight two-line stack, centred. Section titles drop to about 24px, and code snippets and stats switch to Mona Sans Mono in small green or grey. The weight is light for the size, so the headline reads calm rather than loud.

## Layout and rhythm
A single narrow column between two 1px vertical rules, with the nav spanning wider above it. The hero is stacked: announcement chip, headline, a joined email field plus green button, a grey secondary button, then a large pale pixel-grid canvas below. Later sections alternate centred titles with two-up and three-up card rows, each card holding a miniature product UI. A scrolling ticker of live stats sits between hero and platform.

## Shape, depth and texture
Corners are small (6px buttons, soft cards) and depth is almost flat: hairline borders instead of shadows. Imagery is product UI shown as small framed fragments (pull request, workflow, code diff) plus a 3D-ish pink octocat mascot. The grid background is a faint graph-paper texture.

## Motion
Not observed. A live stats ticker scrolls sideways between the hero and the platform section.

## Why it does not look generic
Instead of a product screenshot, the hero gives the empty space to a pixel grid and a peeking mascot, so the brand feels like play rather than enterprise. Coloured rules in segments tie the page together without filling any area with colour.

## Steal this
- Segment a hairline divider into several flat colours, one per grid column, so sections get a signature edge with no extra layout.
- Show each product feature as a cropped, miniature UI card on a pale grey tile instead of an icon.
- Pair a joined email input and primary button in one grey capsule, with a secondary button beside it, so sign-up is the hero's only action.

## Not for
Brands that need a dense, data-first or luxury feel; the airy centred column wastes space.
