# Locomotive

**In one line:** this entry describes the work index (locomotive.ca/en/work), because the homepage returned only a bot-check page; it is a Montreal studio's project list set as plain text.

## Colour
White background and black text, nothing else. The extracted blue (#312DFB) and crimson (#DC143C) did not appear in the captured work page, so they are listed from the site's stylesheet only.

## Type
One regular grotesque at about 17 to 20px for everything: nav, intro, project names and categories. The intro sentence ("We design, develop and ship digital products...") is set in a narrow block at the same size as the list. The footer switches to a thin condensed display face at very large size, mixing letters with small icon glyphs in the address line ("1211 Jean-Talon Est, Montreal, Canada H2R 1W1, Telephone, info@locomotive.ca").

## Layout and rhythm
A six-column feel on a 1280 viewport with two active columns. Top row: "Locomotive®" at the left edge, a small logo glyph, the nav ("Work, Agency, Careers, Store") starting at the halfway line, "Let's talk" at the right edge. The next band holds the filter label "All projects" with a superscript count (47) at left and the intro paragraph aligned to the halfway line. Then comes the list: 47 rows, one line each, project name at left, industry (Music, Transportation, Media, Energy, Fashion, Hospitality) from the halfway line, and (+) at the right edge. A small three-column link block and the oversized address footer end the page.

## Shape, depth and texture
No boxes, no borders, no images in view. The only ornaments are the (+) markers and the icon glyphs in the footer.

## Motion
Not observed. The (+) markers suggest rows expand.

## Why it does not look generic
A studio known for visual work shows none of it at first: the index is a typographic table, so the list of clients and sectors is the proof. The halfway-line alignment makes the whole page a two-column grid.

## Steal this
- Present a portfolio as a one-line-per-row table (name, sector, plus sign) and reveal the image only on interaction.
- Align the intro text, nav and category column to the same halfway line so the grid is visible without lines.
- End the page with a giant condensed address line that mixes icon glyphs into the text.

## Not for
Studios that must sell through imagery on first view, and sites with fewer than a dozen projects, where a table looks sparse.
